# JobFlow AI

A simple mobile-friendly booking and job tracker for solo service businesses.

## Starter features
- Add jobs with customer, service, time and price
- See upcoming bookings and unpaid balances
- Mark jobs paid and remove jobs
- Voice dictation where supported
- Reminder alerts while the page stays open
- Data saved locally in the browser

## Run
Open `index.html` in a browser. Microphone features may need HTTPS.

## Limitations
This is an **early prototype**. Bookings are kept only in that browser and are not synced across devices. Reliable background notifications, Google Calendar integration, logins, cloud backup, automatic customer messaging and payments are not yet implemented.

## Next steps
Test with real business owners, then build secure accounts, cloud storage, background reminders and optional calendar connections.
